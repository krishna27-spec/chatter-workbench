Chatter Workbench

Desktop software for chatter detection and spindle speed control in micromilling.

Download for Windows

Install

  1. Open the page above and download ChatterWorkbench-Setup-<version>.exe.
  2. Run it. The installer is not code-signed, so Windows may warn about an unknown publisher: choose More info, then Run anyway.
  3. For live use, also install the free NI-DAQmx driver. Opening recordings does not need it.

What it does

  • Opens .lvm and .csv recordings with time, spectrum and spectrogram views.
  • Three trained models report no cutting, stable or chatter every 25.6 ms.
  • Computes a new spindle speed with the Liao & Young rule. Output is off by default, and suppression has not yet been shown on a machine.
